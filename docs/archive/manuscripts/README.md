# 보존 원고

화면에 나가지 않는 옛 원고다. 지우지 않고 보관만 한다(사용자 결정, 2026-11-23). 빌드·검증·테스트가 읽지 않는다.

- `summaries.json`: 옛 ‘5분 요약’(sections, takeaways, note)
- `mini-course-extras.json`: 옛 미니강좌 필드(sections, question, answer). 원래 `data/mini_courses.json`에 있었다.

강의 내용의 원본은 `data/lecture_compact.json`(도입·상세 요약·타임스탬프·편집자 주)과 `data/mini_courses.json`(한 문장)이다.
