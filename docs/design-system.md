# 디자인 기준 (현행만)

> 현행 기준만 둔다. 이전 녹색 팔레트·미니멀 모던·메뉴 2개·5분 요약 시기의 설명은 `docs/archive/design-system-2026-11-07.md`에 보존했다. 최종 기준은 `assets/site.css`의 `:root` 토큰과 마지막 레이어(v10 → v11), `assets/site.js`의 공통 동작이다.

## 1. 공통 토큰
| 범주 | 토큰 | 값/역할 |
|---|---|---|
| 배경 | --paper / --surface | #f5f5f6 / #ffffff |
| 글자 | --ink / --muted | #0f0f10 / #5e5e66 |
| 강조 | --accent / --tint | #c8102e / rgba(15,15,16,.05) |
| 경계선 | --line | rgba(15,15,16,.12) |
| 카드 | --radius-card | 6px (--radius 참조) |
| 버튼 | --radius-control | 4px |
| 본문 | --font-body-size / --line-height-body | 16px / 1.8 |
| 작은 UI | --font-ui-size | 14px |
| 간격 | --space-1, 2, 3, 4, 5, 6, 8, 12 | 4, 8, 12, 16, 20, 24, 32, 48px |
| 레이아웃 | --site-max-width | 1160px |
| 터치 | --tap-target | 최소 44px |
| 버튼 여백 | --button-pad-y / --button-pad-x | 9px / 15px |

새 색상·크기·반경을 도입하기 전에 이 토큰을 우선 사용한다. 디자인 자체를 변경할 때만 문서·토큰·검사를 같은 PR에서 갱신한다. 기존 CSS의 하드코딩 값은 순차적으로 이관하며, 전체 재작성으로 기존 화면을 흔들지 않는다.

## 2. 공통 구성과 반응형
- 모든 페이지: 공통 헤더·본문·푸터, 한 페이지 h1 하나, 44px 이상 터치 대상, 읽기 쉬운 왼쪽 정렬.
- 홈: lectures.json + scripts/build_library.py가 유일한 카드 데이터 원본이며 수동 카드 추가 금지.
- 강의: data/lecture_compact.json(타임스탬프·출처) + data/mini_courses.json(한 문장·핵심 세 가지) → scripts/build_compact_lectures.py.
- 모바일 기준 분기점은 780px 이하, 매우 작은 화면 보정은 360px 이하를 유지한다. 좁은 화면은 한 열 본문, 가로 넘침 없이 자연스러운 줄바꿈, 최소 16px 입력 글꼴을 지킨다.
- 본문 코드블록은 pre-wrap / overflow-wrap을 유지하되 댓글 원문의 줄바꿈·시간정보·공백을 복사 과정에서 변경하지 않는다.
- sticky 메뉴·해시 앵커·접힌 영역 열기 동작을 유지한다. 기존 URL 앵커는 삭제하지 않는다.

## 3. 공통 상호작용 계약
- 댓글 복사는 data-copy-target이 가리키는 원문 textContent만 복사한다.
- 성공: 버튼 '복사 완료 ✓', 상태 '복사됨'. 2.2초 후 버튼 원래 이름과 상태 문구가 복원된다.
- 실패: 원문을 선택하고 '텍스트 선택됨' 및 직접 복사 안내를 제공한다.
- 상태는 role=status와 aria-live=polite로 알린다. 복사 버튼은 모바일에서도 폭을 독점하지 않는다.

## 4. AI 변경 절차와 검증 증거
1. AGENTS.md → 편집규칙.md → 이 문서 → 저장소 스킬을 읽고 현행 레이아웃과 데이터 생성 경로를 확인한다.
3. 로컬 검사: python3 scripts/validate_design_system.py; python3 scripts/validate_site.py; python3 -m unittest discover -s tests; node --test tests/*.cjs.
4. PR의 네 가지 항목: 변경 범위 / 영향 기능 / 검증 증거 / 남은 위험. GitHub Actions의 정적·상호작용·반응형 스모크 결과를 확인한다.
5. 브라우저 자동화 검사는 실물 아이폰 Safari 검사의 대체물이 아니다. 검증하지 않은 환경은 미검증으로 기록하고, 배포 링크는 실제 공개 파일 확인 후 공유한다.

## 5. 변경 금지와 예외
- UI 작업 시 강의 텍스트·원자료·영상 시각·원문 댓글·진행 기록을 의도 없이 수정하지 않는다.
- 디자인 토큰 변경은 관련 페이지와 모바일/PC 화면에 대한 영향 분석을 포함해야 한다.
- 과거 레이아웃을 되살리는 변경은 명시적 사용자 요청이 없는 한 금지한다.
- 새 규칙은 기존 규칙과 중복·충돌하지 않는지 확인하고 AGENTS.md, 편집규칙.md, 스킬, 테스트 중 필요한 곳을 함께 갱신한다.

## 6. 한국어 화면 문구
- 간결하고 자연스러운 한국어가 기준. 모든 문장을 ‘~한다/~이다’로 끝내는 획일적 문체 강제 금지.
- 페이지 제목과 중복되는 소개 문구는 과감히 줄이거나 삭제한다. 상태는 ‘아직 기록 없음’, ‘불러오는 중’처럼 바로 이해되게 표현한다.
- 용어 카드에는 정확한 정의와 중요한 구별만 남긴다. UI에는 간결한 명사구, 해설에는 자연스러운 완결문을 적절히 사용한다. 문장 끝을 일괄 치환하지 않는다.
- 학습 콘텐츠의 연구·인과·한계·출처는 스타일을 이유로 삭제하지 않는다. 최신 세부 기준은 편집규칙.md의 ‘한국어 문체와 화면 문구’에 둔다.

## 동작 규칙 (2026-11-06 인터랙티브 스타일 중 현행)
- 호버는 마우스 환경에서만. 카드는 경계선·제목이 강조색으로 바뀌고 빨간 기운의 얕은 그림자가 생긴다(v10).
- 눌림: 버튼·칩 scale(.97). 전환 .16초, 곡선 --ease-out.
- 등장: 홈·강의 섹션은 아래에서 10px 올라오며 나타나고 카드는 최대 .25초까지 순차 지연한다. details를 펼치면 내용이 4px 아래에서 나타난다.
- `prefers-reduced-motion: reduce`에서는 애니메이션·전환을 끈다. 애니메이션은 transform과 opacity만 쓴다.

## 블랙·레드·그레이 / v10 (2026-11-06 · 현행 시각 기준)
- **방향:** 슬릭하고 시크한 화면. 검정과 회색이 바탕이고, 빨강은 얇은 강조(제목 아래 짧은 선, 라벨, 링크 밑줄, 목록 번호, 진행 막대, 포커스, 카드 호버)에만 쓴다. 넓은 면을 빨강으로 칠하지 않는다.
- **라이트:** 배경 #f5f5f6, 면 #ffffff, 글자 #0f0f10, 보조 #5e5e66, 강조 #c8102e(흰 배경 대비 약 5.9:1).
- **다크:** 배경 #0b0b0c, 면 #131315, 글자 #f3f3f4, 보조 #a2a2aa, 강조 #ff4d63(배경 대비 약 6:1).
- **투명도:** 선(--line), 면 톤(--tint), 카드(--card-bg), 태그는 알파값으로 정의해 라이트·다크 어디서나 자연스럽게 겹친다. 헤더는 반투명(--header-bg, 라이트 .78·다크 .76)에 `saturate(180%) blur(16px)`를 적용하고, backdrop-filter 미지원 시 --header-solid로 대체한다. 상단에는 아주 옅은 빨간 광원(--glow) 그라데이션을 둔다.
- **형태:** 모서리 카드 6px, 컨트롤·칩 4px, 태그 3px. 그림자는 카드 호버 때 빨간 기운의 얕은 그림자만 쓴다.
- **타이포:** 시스템 글꼴. 홈 제목·강의 제목은 굵기 800과 음수 자간, 라벨(eyebrow)은 11px·자간 .16em.
- **레이아웃:** 헤더·본문·푸터 모두 최대 폭 760px로 맞춰 브랜드, 제목, 카드의 왼쪽 선을 일치시킨다. 홈 강의 카드는 한 열이다. 모바일 칩 줄은 가로 스크롤이며 오른쪽 끝을 투명 마스크로 흐리게 처리한다.
- **아이콘:** assets/icon.svg는 검정 바탕·빨간 점·회백색 책. PNG(icon-512, apple-touch-icon)는 SVG에서 rsvg-convert로 생성한다. 다크 모드에서는 아이콘 둘레에 가는 선을 둔다.
- theme-color는 라이트 #ffffff, 다크 #0b0b0c, manifest 배경은 #f5f5f6이다.

## 읽기 개선 / v11 (2026-11-07)
- v10 색·투명도 토큰을 그대로 쓰고 읽는 순서만 다듬었다.
- 한 문장: 굵기 600, 빨간 왼쪽 선 3px, 반투명 면(--card-bg). 글자 크기는 PC 17px, 모바일 16px(검사 상한 17px).
- 핵심 세 가지: 기본 번호 대신 빨간 `01·02·03` 카운터와 항목 사이 가는 선.
- 타임스탬프: 한글 간격이 벌어지는 고정폭 글꼴 대신 시스템 글꼴과 `tabular-nums`. 원문 텍스트·복사 결과는 그대로다. 접힌 상태에서는 원문 첫 네 줄을 줄바꿈해 모두 보여 준다. 전체 보기를 열면 타임스탬프 원문을 페이지에서 이어서 읽는다.
- 강의 하단에 `lecture-pager`(← 더 최근 강의 / 지난 강의 →)를 둔다. 순서는 lectures.json(최신순)이며 생성기가 만든다. 모바일은 한 열, 빈 칸은 숨긴다.
- 푸터: 브랜드·강의 목록·테마 버튼 한 줄, 화면 버전은 다음 줄.

## 전체 강의 읽기 개선 / v12 (2026-11-11)
- 기존 색상·테마·760px 읽기 폭을 유지한다. 홈은 검색 → 주제 → 목록의 한 열 구성이며(기본 최신순, 목록 위 정렬 버튼으로 ‘최신순’(강의 날짜)·‘추가된순’(`added`)을 고르고 선택은 `?sort=added`·localStorage로 유지), 모바일 첫 화면에 첫 강의 제목이 보이도록 한다.
- 강의 제목 아래에 이 페이지의 목차를 둔다. 핵심 요약 / 실천 포인트(옛 형식) 또는 도입 / 타임스탬프 또는 상세 요약 / 참고 자료로 이동하며, 스크롤 중 현재 위치를 표시한다. 전역 상단 메뉴는 추가하지 않는다.
- 목차는 헤더 바로 아래에 붙는다. 링크와 앵커는 JS 없이도 이동하고, 현재 위치 표시만 JS로 보완한다.
- 실천 포인트는 세 가지 행동을 담은 면과 단계별 details로 구분한다. 설명 펼치기와 원본 이동을 별도 동작으로 두고, 김주환 강의는 확인된 영상 시각, 그 외 강의는 상세 요약의 소제목으로 연결한다.
- 강의 본문, 실천 목록, 상세 해설, 출처, 이전·다음 강의의 간격과 제목 크기를 공통 CSS에서 조정한다. 라이트·다크 및 세 가지 강조색을 그대로 지원한다.
- 인쇄 시 목차와 펼침 표시를 숨기고 타임스탬프 전체를 출력한다.

## 읽기 진행 막대 / v2026.11.11.6
- 스크롤 목표값을 requestAnimationFrame에서 시간 기반 지수 보간(85ms 시정수)으로 따라간다. CSS 스크롤 타임라인과 transition은 중복 적용하지 않는다.
- 목표에 도달하면 프레임 요청을 멈춘다. 페이지 복원 시 즉시 동기화하고, 펼침·접힘에 따른 본문 높이 변화도 반영한다. 동작 줄이기 설정에서는 보간을 생략한다.

## 모바일 진행 막대 표시 / v2026.11.11.7
- 진행 막대를 화면 최상단에서 고정 헤더 하단으로 옮긴다. 모바일 브라우저 상단 영역과 safe area에 걸리지 않도록 헤더 안에서 배치하며 PC에도 같은 위치를 적용한다.
- 진행 전에도 옅은 트랙을 표시하고, 기존 시간 기반 보간과 동작 줄이기 설정을 유지한다. 모바일 터치·PC 폭과 Chromium·WebKit에서 표시 위치와 채워짐을 검증한다.

## 상세 요약 읽기 / v13 (2026-11-12)
- 상세 요약 제목 아래에 소제목 목차(`.detail-toc`)를 둔다. 생성기가 `detail`의 소제목으로 만들며 `#detail-N`으로 이동한다. PC는 두 열, 모바일(780px 이하)은 한 열이고 각 항목은 44px 이상이다. 인쇄 때는 숨긴다.
- 상세 요약 본문은 PC 17px·줄 길이 38em(한글 약 38자), 모바일 16px이다. 그 밖의 색·간격·토큰은 v12 그대로다.
- 실천 포인트 마지막 묶음의 아래 선을 없애 다음 섹션의 위 선과 겹치지 않게 한다.

## 깊이 서재 / v14 (2026-11-17)
- **방향:** 한 문장 → 핵심 세 가지 → 실천 → 상세 요약 → 원본 시각으로 내려가는 읽기. v10 색·투명도 토큰, 760px 폭, 상단 메뉴 없음은 그대로다.
- **CSS 정리:** 지금 페이지에 없는 클래스(5분 요약·미니강좌·개념집·옛 메뉴 등)를 겨냥한 규칙을 지웠다. 정리 전후 모든 강의 페이지의 계산 스타일이 360·390·1280px, 라이트·다크에서 같았다.
- **홈:** 제목 아래 `오늘의 한 문장`(`.today-line`). 스크립트가 날짜마다 다른 강의의 한 문장으로 바꾸고, 스크립트가 없으면 최신 강의가 보인다. 카드는 설명 대신 한 문장 핵심(`.card-lead`, 3줄)을 보여 주고 태그는 둘만 보인다. 설명·전체 태그는 검색어로 계속 찾힌다.
- **주제 묶음:** 칩은 `lectures.json`의 `topic`(명상·마음근력·감정과 뇌·몸과 수면)으로 만든다. 주제와 검색어는 함께 걸리고, 같은 칩을 다시 누르면 전체로 돌아간다. 주소에는 `?topic=`으로 남는다. 모바일에서는 검색 라벨을 시각적으로 숨기고 칩 개수를 감춘다.
- **등장 효과:** 강의 본문·제목·검색 영역의 페이드업을 없앴다. 홈 카드만 .3초, 최대 .08초 지연으로 나타난다.
- **실천 포인트:** 오늘의 실천 세 가지는 번호 원이 붙은 카드 세 장이다.
- **상세 요약:** 소제목마다 위에 가는 선을 두고, 소제목 바로 다음 문단을 조금 진하게 해 절의 요지를 먼저 읽게 한다. 문장은 바꾸지 않는다.
- **편집자 주:** 본문에는 강의 내용만 둔다. 한계·보충 자료·확인하지 못한 항목은 페이지 맨 끝 접힌 ‘출처와 편집자 주’(`details.source-disclosure`, id `lecture-sources`) 안의 ‘편집자 주’(`div.editor-notes`, id `lecture-editor`)에 묶음별 목록으로 모은다. 묶음 제목은 작은 소제목, 항목은 작은 회색 글씨이다. 도식은 이해에 실제로 도움이 될 때만 쓰고, 이상하거나 쓸모없는 도식은 넣지 않는다.
- **타임라인 막대:** 2026-11-23에 없앴다(아래 ‘타임스탬프 구간 단순화’).
- **깊이 목차:** 읽는 중에는 오른쪽 아래 `목차 · 현재 섹션` 버튼이 뜨고, 누르면 섹션과 상세 요약 소제목을 한 시트(`dialog.outline-sheet`)로 보여 준다. 푸터가 보이면 버튼을 숨긴다. 기존 `reading-nav`와 진행 막대는 유지한다.
- **보기 설정:** 푸터의 `보기 설정`을 펼치면 강조 색과 글자 크기(작게·보통·크게, `--reading-scale` .92·1·1.14)를 고른다. 화면 테마 버튼은 늘 보인다. 값은 이 기기에만 저장한다(`study-site-text-size`). 기본 크기 상한(한 문장 17px, 목록 16px)은 그대로다.
- **공유 메타:** 강의마다 `description`·`og:description`이 그 강의의 한 문장 핵심이다. 이미지는 `assets/icon-512.png`.
- **하지 않은 것:** 웹폰트는 오프라인 캐시 용량 때문에 넣지 않았다(시스템 글꼴 유지). 읽던 위치 저장은 당시 넣지 않았으며, 2026-11-24 탐색 개선에서 브라우저에 마지막 한 곳만 저장하도록 변경했다. 강의별 공유 이미지(og:image)는 아이콘으로 대신한다. 강의 페이지의 대표 이미지는 2026-11-21부터 아래 규칙으로 선택해서 쓴다.

## 타임스탬프 구간 단순화 (2026-11-23 사용자 요청)
- 타임스탬프 섹션은 제목, `타임스탬프 복사` 버튼, 타임스탬프 원문(첫 네 줄 미리보기와 ‘전체 타임스탬프 보기’)만 둔다.
- 이전의 `▶ 이 페이지에서 영상 보기` 버튼과 16:9 플레이어(`.video-embed`, youtube-nocookie), 장·핵심 세션 위치를 그린 타임라인 막대(`.time-map`)와 범례는 없앴다. 스크립트와 스타일도 함께 지웠다.
- 도입 해볼 일의 `영상 N부터 보기` 링크는 새 탭에서 유튜브를 그 시각부터 연다(`target="_blank" rel="noopener"`). 테스트가 임베드와 막대가 다시 생기는 것을 막는다.

## 조용한 서재 / v15 (2026-11-18)
- **방향:** 한 문장이 주인공이다. 색 토큰·테마·강조 색 선택·760px 폭·상단 메뉴 없음은 그대로 두고, 상자와 장식을 덜어 낸다.
- **홈:** `강의 요약` 제목은 26px(모바일 22px)로 낮추고 빨간 밑줄을 없앴다. `오늘의 한 문장`은 상자 없이 22~28px(모바일 20px) 굵은 글자로 크게 보인다. 출처 줄의 화살표를 뺐다. 검색 라벨은 화면에서 숨기고 스크린리더에는 남긴다.
- **강의 목록:** 카드 상자 대신 위아래 가는 선으로 나눈 색인 행이다. 태그 칩과 `핵심 요약과 타임스탬프 →` 줄을 없앴다(태그는 검색에 그대로 쓰인다). 마우스를 올리면 제목만 강조색이 된다. 등장 애니메이션은 쓰지 않는다.
- **강의 머리:** 제목 위 `강의 요약` 라벨을 없애고 제목을 40px(모바일 28px)로 키웠다.
- **한 문장:** 흰 상자 대신 강조색 왼쪽 선 하나. 글자 크기 상한(17px)은 그대로다.
- **핵심 세 가지:** 순서가 아니므로 `01·02·03` 대신 강조색 점을 쓴다. 상세 요약 목차의 번호는 실제 순서라서 유지한다.
- **라벨:** 자간을 넓힌 라벨(`.eyebrow`, 정렬·이전 강의 라벨 등)을 일반 자간으로 되돌렸다. 배경의 붉은 빛 번짐도 없앴다.
- **목록 기호 위치(2026-11-18 보완):** 핵심 세 가지의 점과 오늘의 실천 번호 원은 고정 `top` 값 대신 글자 흐름에 붙인다(점은 인라인, 번호 원은 숫자와 문장의 기준선 맞춤). 글자 크기·줄 수·기기와 상관없이 첫 줄에 놓인다. 브라우저 테스트가 360·390·1280px, 작게·보통·크게에서 첫 줄과 3px 넘게 어긋나는 절대 위치 기호가 없는지 검사한다.

## 디자인 검토 반영 / v2026.11.19.1
- **앵커 위치:** 강의 페이지에서는 `--anchor-offset`이 헤더 높이 + 목차(`reading-nav`) 높이 − 1px이다. 목차나 깊이 목차로 이동하면 섹션의 위 선이 목차 아래 선과 겹쳐 한 줄로 보이고, 두 줄 사이 빈 띠가 생기지 않는다.
- **현재 위치 표시:** 섹션 위쪽이 목차 아래에서 화면 높이의 25%(최소 32px) 안에 들어오면 그 섹션을 현재 위치로 표시한다. 페이지 끝에 닿으면 마지막 항목(참고 자료)을 표시한다.
- **목차 버튼:** `outline-fab`은 반투명 유리 대신 불투명한 면(`--surface`)이라 아래 본문 글자와 겹쳐 읽히지 않는다.
- **오늘의 한 문장:** PC 19~22px, 모바일 18px으로 한 단계 낮췄다. 굵기와 상자 없는 형태는 v15 그대로다.
- **강의 하단:** 이동 경로·이전/다음 강의와 겹치던 `강의 목록` 버튼(`.summary-links`)을 없앴다.
- **유지한 결정:** 화면 테마와 보기 설정은 푸터에 둔다(헤더에 두지 않음). 타임스탬프 원문 줄은 링크로 만들지 않고 막대가 시각 링크 역할을 한다(2026-10-30 결정).

## 헤더 높이와 스크롤 자동 숨김 (2026-11-21 사용자 요청)
- PC 헤더는 한 줄(약 45px)이다. 로고 28px, 「내면의 서재」 옆에 부제를 같은 줄에 둔다. 모바일 높이는 그대로다.
- 본문을 아래로 스크롤하면 헤더가 위로 숨고, 위로 올리면 다시 보인다. 맨 위 근처, 헤더 안 초점 이동 중, 인쇄, 모션 줄이기 설정에서는 항상 보이거나 움직임이 없다.
- 헤더가 숨으면 강의 목차(`.reading-nav`)와 사이드바가 화면 맨 위에 붙는다(`html.header-hidden`). 읽기 진행 막대는 숨은 헤더 안에서도 화면 맨 위에 남는다.

## 강의 대표 이미지 (2026-11-21 사용자 요청)
- `lectures.json`의 `image`(`src`·`alt`·`width`·`height`)가 있는 강의에만 헤더 바로 아래에 한 장을 둔다(`figure.lecture-hero`). 없는 강의는 그대로이다. 홈 카드에는 이미지를 넣지 않는다.
- 파일은 `assets/lectures/<강의 id>.jpg`, 450KB 이하의 JPEG이다. 폭 1600px 안팎으로 줄여 저장한다.
- 이미지는 AI 티가 나지 않는 자연스러운 사진 느낌으로 만든다(ChatGPT 이미지 도구). 글자, 인물 얼굴, 과한 빛 연출은 쓰지 않는다.
- 서비스 워커는 `image`가 있는 강의의 이미지도 함께 저장한다. `tests/test_lecture_images.py`가 크기·alt·위치를 검사한다.

## 상세 요약 안 이미지 (2026-11-21 사용자 요청)
- 상세 요약 문단 사이에 `{"image": {"src","alt","width","height","caption"}}` 항목을 둘 수 있다(`figure.detail-figure`, `lazy`). 글을 블로그처럼 쉽게 읽히게 하려는 용도이다.
- 한 강의에 최대 3장이다. 파일은 `assets/lectures/<강의 id>-<이름>.jpg`, 450KB 이하이다. alt는 120자 이하, 캡션은 선택이며 120자 이하이다.
- 이미지는 그 문단의 비유나 장면을 보여 줄 때만 쓴다. 대표 이미지와 같은 규칙(AI 티가 나지 않는 사진 느낌, 글자·얼굴 금지)을 따른다.
- 서비스 워커는 이 이미지를 미리 저장하지 않는다. 처음 본 뒤에 캐시에 쌓인다. `tests/test_lecture_images.py`가 개수·크기·alt·순서를 검사한다.

## 핵심 요약 섹션
- 첫 섹션과 목차 이름은 `핵심 요약`이다. `#lecture-overview`와 옛 `#lecture-practice` 링크는 유지한다.
- 핵심 주장 목록 → 한 문장 인용 → 필요한 실천 블록 순서다. 핵심 주장은 폭을 제한한 점 목록에 두고 항목 사이 구분선을 사용하지 않는다.
  - `points`: 기존 핵심 목록과 같은 점 목록(`.summary-list`). 구분을 이름 붙인 항목은 굵은 라벨 뒤에 문장이 온다.
  - `practice`: 카드 목록(`.practice-list`). 카드 하나에 `언제·할 일` 두 줄과, 있을 때만 `확인` 한 줄(`dl.practice-cells`, 라벨은 강조색 13px, 본문 15px), 강연자 인용(`blockquote.practice-quote`, 14px, 왼쪽 선), 영상 시각 링크(`.practice-source`)가 순서대로 있다. 다른 강연자는 영상 대신 상세 요약 소제목으로 연결한다.
  - `steps`: 기존 실천 포인트의 단계 펼침(`details`)을 그대로 쓴다(`.intro-steps`가 같은 규칙을 받는다). 설명 펼치기와 원본 이동은 별도 동작이다.
- 글자 크기는 읽기 크기 설정(`--reading-scale`)을 따르고, 색은 토큰만 쓴다. 320·390·1280px, 라이트·다크에서 가로 넘침이 없어야 하며 `tests/browser-smoke.spec.cjs`가 확인한다.

## 페이지 구조 개편 (2026-11-23)
- **해볼 일 카드 위계:** 카드 안에서 `할 일`(16px·굵게·본문색, 라벨은 강조색)이 주이고, `언제`와 `확인`은 보조(14px·보통·회색, 라벨은 회색)이다. 인용은 13px 회색에 왼쪽 선, 영상 링크는 12.5px·보통 굵기이다. 카드 안여백은 모바일 12·14px, PC 14·16px, 카드 사이 10px이다. 확인 칸이 없으면 두 줄만 그린다.
- **도입 밀도:** 핵심 주장 목록의 항목 위아래 여백을 18에서 12px로, 도입 블록 사이 간격을 22에서 18px로 줄였다. 모바일 도입 높이는 브라우저 테스트가 지킨다(`intro stays compact…`).
- **하단 통합:** 접힘 하나 `출처와 편집자 주`(`details.source-disclosure#lecture-sources`) 안에 `원본과 참고 자료`(`.notes-block`)와 `편집자 주`(`.editor-notes#lecture-editor`)를 소제목으로 구분해 둔다. 편집자 주로 바로 가는 링크도 접힘을 연다. 목차 링크는 `출처`이다.
- **라벨:** 이전 강의 링크는 `← 최근 강의`, 다음은 `지난 강의 →`로 짝을 맞췄다.
- **하단 여백:** 본문 아래 군집을 출처 접힘 28px → 이전·다음 28px → 푸터 순으로 맞췄다. 푸터 앞 합계는 72px에서 52px로 줄었다.



## 상단 보기 설정과 개인 서재

- 상단 ‘Aa’ 패널에서 글자 크기와 화면 테마를 고른다. 강조 색은 사이트 팔레트를 따른다. 페이지 생성기가 공통 헤더와 초기 설정 스크립트를 내보낸다.
- 강의 행은 제목 링크를 행 전체로 펼치고, 별·체크 버튼은 그 위에서 독립적으로 작동한다. 읽음 상태와 북마크는 이 브라우저에 저장한다.
- 상세의 한 문장, 연습 카드, 타임스탬프와 본문 인용은 공통 배경·텍스트·선 변수를 사용한다.

## 홈 탐색과 읽기 표면

- 홈 검색 입력은 둥근 형태로 강조하고, 주제 칩과 북마크의 선택 상태에는 옅은 청회색 면을 사용한다. 라이트·다크에서 선택 글자는 본문색을 쓴다.
- 오늘의 한 문장에는 별도의 청회색 면을 두고, 강의 목록은 한 열의 테두리 카드로 정리한다. 강의 페이지의 상세 목차와 출처에도 같은 모서리 규격을 쓴다.
- 기존 검색·정렬·읽음 동작과 44px 터치 영역을 따른다. 검색 패널에 새 조작 요소를 추가할 경우 이미 제공하는 동작과 겹치는지 확인한다.


## 깊이 읽는 디지털 서재
- 종이색과 차콜, 딥 슬레이트와 밝은 회색을 기본 팔레트로 쓰며, 공통 콘텐츠 폭의 상한은 800px이다.
- 탐색 패널의 둥근 검색창과 푸른 선택 상태를 사용한다. 정렬은 네이티브 선택 상자로 조작한다.
- 오늘의 한 문장은 로컬 명조 계열을 사용한다. 강의 행은 제목, 핵심 요약, 주제와 강의 정보 순서다. 주제 배지에는 테마별 색과 텍스트 라벨을 사용한다.


## 강의 선택과 이어 읽기 (2026-11-24)
- 목록과 강의 머리에 핵심 요약·상세 요약의 예상 읽기 시간을 표시한다. 공백 제외 분당 500자를 기준으로 올림한 대략값이며, 원본 영상 길이·타임스탬프·편집자 주·화면에 없는 실천 블록은 제외한다. 영상 길이에는 ‘원본’을 붙인다.
- 검색은 기존 키워드와 핵심 주장에 더해 상세 요약 본문도 찾는다. 결과에 검색된 문맥을 안전한 텍스트 노드로 표시하고 검색어를 강조한다. 제목·본문이 일치한 소제목으로 바로 이동할 수 있다. 검색 중 오늘의 문장은 접고 검색 해제 시 복원한다.
- 저장·읽음 버튼에 보이는 문구를 붙이고 기존 aria-label과 44px 터치 영역을 유지한다. 헤더 설정에는 ‘보기’를 함께 쓴다. 내부 강의 링크는 외부 이동 화살표를 쓰지 않는다.
- 오늘의 문장을 약간 압축하고 종이색·명조체·800px 폭·카드 구성은 유지한다.
- 상세 요약 소제목 목록은 기본 접힘 details로 제공한다. 기존 앵커·고정 목차·깊이 목차는 유지하며, 소제목 해시로 들어오면 소제목 목록을 펼치지 않고 본문으로 이동한다.
- 이어 읽기는 마지막 미완독 강의의 id·소제목 id·라벨 한 곳만 이 브라우저에 저장한다(`study-hub-resume`). 자동 복원이나 서버 전송은 없으며, 홈에서 명시적으로 링크를 누른다. 지우기와 읽음 완료 시 제거한다. 검색·주제 필터와는 독립이다.
