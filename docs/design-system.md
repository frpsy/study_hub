# 디자인 기준 (현행만)

> 현행 기준만 둔다. 이전 녹색 팔레트·미니멀 모던·메뉴 2개·5분 요약 시기의 설명은 `docs/archive/design-system-2026-11-07.md`에 보존했다. 최종 기준은 `assets/site.css`의 `:root` 토큰과 마지막 레이어(v10 → v11), `assets/site.js`의 공통 동작이다.

## 1. 공통 토큰
| 범주 | 토큰 | 값/역할 |
|---|---|---|
| 배경 | --paper / --surface | #f5f5f6 / #ffffff |
| 글자 | --ink / --muted | #0f0f10 / #5e5e66 |
| 강조 | --accent / --tint | #c8102e / rgba(15,15,16,.05) |
| 경계선 | --line | rgba(15,15,16,.12) |
| 카드 | --radius-card | 6px (--radius 참조) |
| 버튼 | --radius-control | 4px |
| 본문 | --font-body-size / --line-height-body | 16px / 1.8 |
| 작은 UI | --font-ui-size | 14px |
| 간격 | --space-1, 2, 3, 4, 5, 6, 8, 12 | 4, 8, 12, 16, 20, 24, 32, 48px |
| 레이아웃 | --site-max-width | 1160px |
| 터치 | --tap-target | 최소 44px |
| 버튼 여백 | --button-pad-y / --button-pad-x | 9px / 15px |

새 색상·크기·반경을 도입하기 전에 이 토큰을 우선 사용한다. 디자인 자체를 변경할 때만 문서·토큰·검사를 같은 PR에서 갱신한다. 기존 CSS의 하드코딩 값은 순차적으로 이관하며, 전체 재작성으로 기존 화면을 흔들지 않는다.

## 2. 공통 구성과 반응형
- 모든 페이지: 공통 헤더·본문·푸터, 한 페이지 h1 하나, 44px 이상 터치 대상, 읽기 쉬운 왼쪽 정렬.
- 홈: lectures.json + scripts/build_library.py가 유일한 카드 데이터 원본이며 수동 카드 추가 금지.
- 강의: data/lecture_compact.json(타임스탬프·출처) + data/mini_courses.json(한 문장·핵심 세 가지) → scripts/build_compact_lectures.py.
- 모바일 기준 분기점은 780px 이하, 매우 작은 화면 보정은 360px 이하를 유지한다. 좁은 화면은 한 열 본문, 가로 넘침 없이 자연스러운 줄바꿈, 최소 16px 입력 글꼴을 지킨다.
- 본문 코드블록은 pre-wrap / overflow-wrap을 유지하되 댓글 원문의 줄바꿈·시간정보·공백을 복사 과정에서 변경하지 않는다.
- sticky 메뉴·해시 앵커·접힌 영역 열기 동작을 유지한다. 기존 URL 앵커는 삭제하지 않는다.

## 3. 공통 상호작용 계약
- 댓글 복사는 data-copy-target이 가리키는 원문 textContent만 복사한다.
- 성공: 버튼 '복사 완료 ✓', 상태 '복사됨'. 2.2초 후 버튼 원래 이름과 상태 문구가 복원된다.
- 실패: 원문을 선택하고 '텍스트 선택됨' 및 직접 복사 안내를 제공한다.
- 상태는 role=status와 aria-live=polite로 알린다. 복사 버튼은 모바일에서도 폭을 독점하지 않는다.

## 4. AI 변경 절차와 검증 증거
1. AGENTS.md → 편집규칙.md → 이 문서 → 저장소 스킬을 읽고 현행 레이아웃과 데이터 생성 경로를 확인한다.
3. 로컬 검사: python3 scripts/validate_design_system.py; python3 scripts/validate_site.py; python3 -m unittest discover -s tests; node --test tests/*.cjs.
4. PR의 네 가지 항목: 변경 범위 / 영향 기능 / 검증 증거 / 남은 위험. GitHub Actions의 정적·상호작용·반응형 스모크 결과를 확인한다.
5. 브라우저 자동화 검사는 실물 아이폰 Safari 검사의 대체물이 아니다. 검증하지 않은 환경은 미검증으로 기록하고, 배포 링크는 실제 공개 파일 확인 후 공유한다.

## 5. 변경 금지와 예외
- UI 작업 시 강의 텍스트·원자료·영상 시각·원문 댓글·진행 기록을 의도 없이 수정하지 않는다.
- 디자인 토큰 변경은 관련 페이지와 모바일/PC 화면에 대한 영향 분석을 포함해야 한다.
- 과거 레이아웃을 되살리는 변경은 명시적 사용자 요청이 없는 한 금지한다.
- 새 규칙은 기존 규칙과 중복·충돌하지 않는지 확인하고 AGENTS.md, 편집규칙.md, 스킬, 테스트 중 필요한 곳을 함께 갱신한다.

## 6. 한국어 화면 문구
- 간결하고 자연스러운 한국어가 기준. 모든 문장을 ‘~한다/~이다’로 끝내는 획일적 문체 강제 금지.
- 페이지 제목과 중복되는 소개 문구는 과감히 줄이거나 삭제한다. 상태는 ‘아직 기록 없음’, ‘불러오는 중’처럼 바로 이해되게 표현한다.
- 용어 카드에는 정확한 정의와 중요한 구별만 남긴다. UI에는 간결한 명사구, 해설에는 자연스러운 완결문을 적절히 사용한다. 문장 끝을 일괄 치환하지 않는다.
- 학습 콘텐츠의 연구·인과·한계·출처는 스타일을 이유로 삭제하지 않는다. 최신 세부 기준은 편집규칙.md의 ‘한국어 문체와 화면 문구’에 둔다.

## 동작 규칙 (2026-11-06 인터랙티브 스타일 중 현행)
- 호버는 마우스 환경에서만. 카드는 경계선·제목이 강조색으로 바뀌고 빨간 기운의 얕은 그림자가 생긴다(v10).
- 눌림: 버튼·칩 scale(.97). 전환 .16초, 곡선 --ease-out.
- 등장: 홈·강의 섹션은 아래에서 10px 올라오며 나타나고 카드는 최대 .25초까지 순차 지연한다. details를 펼치면 내용이 4px 아래에서 나타난다.
- `prefers-reduced-motion: reduce`에서는 애니메이션·전환을 끈다. 애니메이션은 transform과 opacity만 쓴다.

## 블랙·레드·그레이 / v10 (2026-11-06 · 현행 시각 기준)
- **방향:** 슬릭하고 시크한 화면. 검정과 회색이 바탕이고, 빨강은 얇은 강조(제목 아래 짧은 선, 라벨, 링크 밑줄, 목록 번호, 진행 막대, 포커스, 카드 호버)에만 쓴다. 넓은 면을 빨강으로 칠하지 않는다.
- **라이트:** 배경 #f5f5f6, 면 #ffffff, 글자 #0f0f10, 보조 #5e5e66, 강조 #c8102e(흰 배경 대비 약 5.9:1).
- **다크:** 배경 #0b0b0c, 면 #131315, 글자 #f3f3f4, 보조 #a2a2aa, 강조 #ff4d63(배경 대비 약 6:1).
- **투명도:** 선(--line), 면 톤(--tint), 카드(--card-bg), 태그는 알파값으로 정의해 라이트·다크 어디서나 자연스럽게 겹친다. 헤더는 반투명(--header-bg, 라이트 .78·다크 .76)에 `saturate(180%) blur(16px)`를 적용하고, backdrop-filter 미지원 시 --header-solid로 대체한다. 상단에는 아주 옅은 빨간 광원(--glow) 그라데이션을 둔다.
- **형태:** 모서리 카드 6px, 컨트롤·칩 4px, 태그 3px. 그림자는 카드 호버 때 빨간 기운의 얕은 그림자만 쓴다.
- **타이포:** 시스템 글꼴. 홈 제목·강의 제목은 굵기 800과 음수 자간, 라벨(eyebrow)은 11px·자간 .16em.
- **레이아웃:** 헤더·본문·푸터 모두 최대 폭 760px로 맞춰 브랜드, 제목, 카드의 왼쪽 선을 일치시킨다. 홈 강의 카드는 한 열이다. 모바일 칩 줄은 가로 스크롤이며 오른쪽 끝을 투명 마스크로 흐리게 처리한다.
- **아이콘:** assets/icon.svg는 검정 바탕·빨간 점·회백색 책. PNG(icon-512, apple-touch-icon)는 SVG에서 rsvg-convert로 생성한다. 다크 모드에서는 아이콘 둘레에 가는 선을 둔다.
- theme-color는 라이트 #ffffff, 다크 #0b0b0c, manifest 배경은 #f5f5f6이다.

## 읽기 개선 / v11 (2026-11-07)
- v10 색·투명도 토큰을 그대로 쓰고 읽는 순서만 다듬었다.
- 한 문장: 굵기 600, 빨간 왼쪽 선 3px, 반투명 면(--card-bg). 글자 크기는 PC 17px, 모바일 16px(검사 상한 17px).
- 핵심 세 가지: 기본 번호 대신 빨간 `01·02·03` 카운터와 항목 사이 가는 선.
- 타임스탬프: 한글 간격이 벌어지는 고정폭 글꼴 대신 시스템 글꼴과 `tabular-nums`. 원문 텍스트·복사 결과는 그대로다. 상자를 누르면 펼치고 접으며, 접힌 상태에서도 안쪽 스크롤은 없다(`overflow:hidden`).
- 강의 하단에 `lecture-pager`(← 더 최근 강의 / 지난 강의 →)를 둔다. 순서는 lectures.json(최신순)이며 생성기가 만든다. 모바일은 한 열, 빈 칸은 숨긴다.
- 푸터: 브랜드·강의 목록·테마 버튼 한 줄, 화면 버전은 다음 줄.

## 전체 강의 읽기 개선 / v12 (2026-11-11)
- 기존 색상·테마·760px 읽기 폭을 유지한다. 홈은 검색 → 주제 → 최신순 목록의 한 열 구성이며, 모바일 첫 화면에 첫 강의 제목이 보이도록 한다.
- 강의 제목 아래에 이 페이지의 목차를 둔다. 핵심 요약 / 실천 포인트 / 타임스탬프 또는 상세 요약 / 참고 자료로 이동하며, 스크롤 중 현재 위치를 표시한다. 전역 상단 메뉴는 추가하지 않는다.
- 목차는 헤더 바로 아래에 붙는다. 링크와 앵커는 JS 없이도 이동하고, 현재 위치 표시만 JS로 보완한다.
- 실천 포인트는 세 가지 행동을 담은 면과 단계별 details로 구분한다. 설명 펼치기와 원본 이동을 별도 동작으로 두고, 김주환 강의는 확인된 영상 시각, 그 외 강의는 상세 요약의 소제목으로 연결한다.
- 강의 본문, 실천 목록, 상세 해설, 출처, 이전·다음 강의의 간격과 제목 크기를 공통 CSS에서 조정한다. 라이트·다크 및 세 가지 강조색을 그대로 지원한다.
- 인쇄 시 목차와 펼침 표시를 숨기고 타임스탬프 전체를 출력한다.

## 읽기 진행 막대 / v2026.11.11.6
- 스크롤 목표값을 requestAnimationFrame에서 시간 기반 지수 보간(85ms 시정수)으로 따라간다. CSS 스크롤 타임라인과 transition은 중복 적용하지 않는다.
- 목표에 도달하면 프레임 요청을 멈춘다. 페이지 복원 시 즉시 동기화하고, 펼침·접힘에 따른 본문 높이 변화도 반영한다. 동작 줄이기 설정에서는 보간을 생략한다.

## 모바일 진행 막대 표시 / v2026.11.11.7
- 진행 막대를 화면 최상단에서 고정 헤더 하단으로 옮긴다. 모바일 브라우저 상단 영역과 safe area에 걸리지 않도록 헤더 안에서 배치하며 PC에도 같은 위치를 적용한다.
- 진행 전에도 옅은 트랙을 표시하고, 기존 시간 기반 보간과 동작 줄이기 설정을 유지한다. 모바일 터치·PC 폭과 Chromium·WebKit에서 표시 위치와 채워짐을 검증한다.

## 상세 요약 읽기 / v13 (2026-11-12)
- 상세 요약 제목 아래에 소제목 목차(`.detail-toc`)를 둔다. 생성기가 `detail`의 소제목으로 만들며 `#detail-N`으로 이동한다. PC는 두 열, 모바일(780px 이하)은 한 열이고 각 항목은 44px 이상이다. 인쇄 때는 숨긴다.
- 상세 요약 본문은 PC 17px·줄 길이 38em(한글 약 38자), 모바일 16px이다. 그 밖의 색·간격·토큰은 v12 그대로다.
- 실천 포인트 마지막 묶음의 아래 선을 없애 다음 섹션의 위 선과 겹치지 않게 한다.
