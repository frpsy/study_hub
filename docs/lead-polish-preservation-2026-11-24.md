# 한 줄 요약 윤문과 원문 보관

기준 커밋: `9aec8c5e17edd718dc47bfd3626d656b08946aee`.

대상은 카드·오늘의 한 문장·상세 상단의 한 줄 요약 22개다. 기존 뜻과 조건을 보존해 20개를 다듬었고, 이미 명확한 2개는 유지했다. 수정 전 문장 전체를 아래에 보관한다.

원본 `mini_courses.json`의 lead와 `lecture_compact.json`의 첫 핵심 문장만 수정했다. 상세 요약, 나머지 핵심 주장, 실천 항목, 직접 인용, 타임스탬프, 출처는 변경하지 않았음을 원본 데이터 전수 비교로 확인했다.

검증: `python3 scripts/build_all.py --check --tests`, `python3 scripts/validate_detail_sync.py`, 전체 Playwright 회귀 검사와 22개 문장의 모바일 두 줄 표시 검사. 세 공개 영역은 동일 원본에서 재생성하며, 최종 결과는 PR의 검증 기록에서 확인한다.
