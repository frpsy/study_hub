# 김주환 강의 문체 기준 (저장소 보관본)

> 김주환 교수의 블로그 글(브런치 @tomasch22)과 같은 평서문 문체로 강의를 정리하는 기준이다. claude.ai 계정의 `kimjuhwan-style` 스킬을 이 저장소에 요약해 둔 것이며, 어떤 도구에서든 이 문서로 같은 문체를 낼 수 있다. 블로그·책 문장은 그대로 옮기지 않고 구조·논리·수사 방식만 따른다.

## 최우선 규칙
- 모든 문장은 평서문(~이다·~한다·~하다)이다.
- "교수님은 ~했습니다", "~하셨다", "~합니다/했습니다"체, "강사는"을 쓰지 않는다. 강연자를 주어로 세우지 않고 내용을 본문처럼 서술한다. 출처를 밝힐 때만 "김주환 교수는 ~라고 설명한다"처럼 짧게 쓴다.
- 비문이 없어야 한다. 쓴 뒤 긴 접속절, 같은 서술어 반복, 추상 명사 표현부터 줄인다.
- 강연자의 견해와 웹에서 확인한 사실을 구분한다. 확인한 문장만 `[보충]`으로 시작한다.

## 구조
1. 소제목은 독자의 의문 순서를 따르는 질문형이다(예: "~란 무엇인가", "왜 ~하지 못하는가", "어떻게 ~할 수 있는가").
2. 기본 흐름은 질문 → 정의 → 근거(연구·사례) → 실천이다. 변형은 사례 → 통념 반박 → 비유로 개념화 → 구체적 처방이다.
3. 도입은 사례나 실험으로 연다. 마지막은 "그래서 무엇을 할 것인가"로 실천을 적고, 이어질 주제나 독자를 격려하는 문장으로 닫을 수 있다.

## 문장과 수사
- 단정적인 단문을 쓴다. 핵심 문장은 표현을 바꿔 한 번 더 말한다.
- "~가 아니라 ~다"로 오해를 먼저 막고 본뜻을 말한다.
- 통념을 제시한 뒤 "사실이 아니다"로 뒤집고 근거를 잇는다.
- 이분법은 세운 뒤 "A는 B의 반대가 아니라 B를 포괄한다"로 묶는다.
- 강조 표지: "분명한 것은", "중요한 것은", "한마디로". 청유와 가정 질문으로 독자를 끌어들인다.

## 비유와 근거
- 추상 개념은 일상 이미지로 푼다(허공과 페인트, 비·눈·바람 같은 날씨). 비유는 대응 관계까지 맞춘다(표로 짝지어도 좋다).
- 뇌과학 용어는 약어와 영어 원어를 병기한다(편도체 amygdala, 전전두피질 PFC). 연구자와 연도는 본문에 적는다.
- 새 개념은 비슷한 개념과의 차이, 번역어를 고른 이유를 밝힌다.
- 종교·철학 이야기는 강연자의 해석임을 밝히고, 학술적 합의처럼 쓰지 않는다.

## 실천과 귀결
- 논의는 편도체 안정화 + 전전두피질 활성화 → 마음근력으로 돌아온다.
- 처방은 구체적으로 쓴다(방법, 시점, 기간). 강연에 기간이 없으면 지어내지 않고 "제시하지 않았다"고 쓴다.

## 핵심 용어
내면소통, 마음근력, 자기조절력, 대인관계력, 자기동기력, 편도체 안정화, 전전두피질 활성화, 알아차림, 자기참조과정, 신경가소성, 내재적 질서와 외재적 질서, 배경자아·경험자아·기억자아, 회복탄력성.

## 출력 점검
- [ ] 모든 문장이 평서문인가(~했습니다, 교수님은, 강사는 없음)
- [ ] 소제목이 질문 순서를 따르는가
- [ ] 정의 다음에 근거가 있는가
- [ ] 통념을 먼저 짚고 바로잡았는가
- [ ] 비유의 대응 관계가 맞는가
- [ ] 실천으로 끝나는가
- [ ] 검증하지 않은 주장과 `[보충]`이 구분되는가
